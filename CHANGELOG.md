# Changelog

What changed in each version of Icon Ctrl, newest first. Versions are x-numbers while Icon Ctrl is a public beta.

## x0.0.2 · 2026-11-03
- A gallery at woodwerd.github.io/icon-ctrl: search the icons, filter by group, open one to see it at label sizes beside its family, and download it.
- Request an icon opens a short issue form.
- Each icon's record now names its telling feature, the shape that makes it read as that tool, and keeps the version it was added in.
- No icons added, changed or withdrawn.

## x0.0.1 · 2026-11-03
- The first Print set: 123 solid icons for power tools, hand tools, consumables, kits and shop places, each drawn from what several makers' versions of a tool have in common.
- Every icon comes as an SVG, as PNGs for print and thermal label sizes, and in one module the WOODWERD tools load.
- Variants read apart from their family at 10 mm, and a variant that isn't in a release falls back to its family's icon.
